### 🎃 Halloween-Dashboard

**Halloween Sales & Event Analytics Dashboard – Tableau**

An interactive **Halloween-themed Tableau dashboard** created using historical event data from **2008–2014**. The dashboard visualizes key metrics such as **6:30 PM event counts, yearly values, trends, and comparisons** through multiple charts and graphs.

The dashboard uses bar charts, line charts, and other visualizations to show year-wise trends, event counts, and value comparisons in an engaging and easy-to-understand format.The dashboard uses a Halloween-themed design to make the data analysis visually engaging while presenting yearly trends and event-related metrics.Interactive Halloween-themed Tableau dashboard analyzing yearly event trends, counts, and values using data visualization.
