### 🎃 Halloween-Dashboard

**Halloween Sales & Event Analytics Dashboard – Tableau**

An interactive **Halloween-themed Tableau dashboard** created using historical event data from **2008–2014**. The dashboard visualizes key metrics such as **6:30 PM event counts, yearly values, trends, and comparisons** through multiple charts and graphs.

### 📌 Key Features

* 🎃 Halloween-themed dashboard design
* 📊 Year-wise data analysis
* 📈 Trend analysis using line charts
* 📉 Bar charts for comparing yearly values
* 🔵 Visual comparison of event counts and values
* 📅 Analysis covering **2008–2014**
* 🎨 Custom background and Halloween-themed visuals
* 📌 Interactive Tableau visualizations

# 🎃 Halloween Sales & Event Analytics Dashboard

This project presents an interactive Halloween-themed dashboard created using Tableau Public. The dashboard analyzes yearly event data from 2008 to 2014 and presents the information through multiple visualizations.

## 📊 Dashboard Highlights

- Year-wise event analysis
- 6:30 PM event count visualization
- Yearly value comparison
- Trend analysis
- Bar charts and line charts
- Interactive dashboard elements
- Halloween-themed visual design

## 🛠️ Tools & Technologies

- Tableau Public
- Data Visualization
- Data Analysis
- Dashboard Design

## 🎯 Objective

The main objective of this project is to transform raw event data into an easy-to-understand and visually engaging dashboard that helps users identify yearly patterns, trends, and comparisons.

## 📅 Data Period

2008 – 2014

## 🎃 Dashboard Preview

The dashboard uses a Halloween-themed background and visual elements to make the analysis more engaging and interactive.
